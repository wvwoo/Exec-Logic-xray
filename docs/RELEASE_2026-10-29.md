# Exec Logic XRay — disclosure-safe release (29 October 2026)

## Release purpose
This is a **reproducible, unweighted, descriptive** evaluation of nonprofit early-warning signals in the Makkah region using 2023–2025 financial periods. It is **not** a professional audit opinion, final survey-weighted v6 estimate, validated prediction of insolvency, or proof of official competition submission.

## Reproduced descriptive findings
- Eligible, grouped primary association units: **92** (49 major-city; 43 other-governorate units), latest fiscal year per association.
- Confirmed signals: **22/92 = 23.9%**; major cities **12/49 = 24.5%**, other governorates **10/43 = 23.3%**.
- Fully evaluable five-flag inputs: **88/92**, four incompletes never considered zeros.
- Critical cash: **6/49** and **10/43**. Negative unrestricted net assets: **9/49** and **8/43**.
- Descriptive Wilson interval for 22/92: about **16.4–33.6%**. No design-based inference.

## Accounting and human-review boundary
The **project leader reports** that Exec Logic members completed human, financial and accounting review. Individual signed decisions tied to each association/year and PDF page were not independently evidenced in the available release. New arithmetic evaluation of the uploaded Ritaj workbook identified **29** activities-change differences, **13** balance-identity differences, and **84** numeric cross-version differences among **311** comparable values with v5 (**41** matching keys, **18** newly unmatched keys). These are review flags, **not** adjudicated accounting errors; none was silently corrected or declared certified. Detailed named data stays in a restricted private audit archive.

## Reproducibility
Run from repository root:

```sh
python scripts/run_analysis.py --input data_clean/indicator_totals.csv --output outputs/public_metrics.json
python -m unittest discover -s tests -v
```

The two-row grouped count input does not contain names, licensing IDs, financial amounts, or detailed reviewer records. It reproduces 12 descriptive percentages and intervals but not the original PDF extraction, full five-indicator rules per association, or sample-weighted inference.
