- [x] Identify team and public repository.
- [x] Add initial README, methodology, and preliminary AI-use log.
- [ ] Independently approve the eligible records or document exclusions.
- [ ] Freeze final data, registry, sample, groups and weights.
- [ ] Publish `analysis.ipynb` OR `scripts/run_analysis.py` implementing the real final Python analysis.
- [ ] Run final analysis end-to-end on reviewed, authorized data.
- [ ] Add a publishable `data_clean/` release, or an organizer-approved access/reproduction method.
- [ ] Add reproducible figures under `outputs/figures/`.
- [ ] Add `report/executive_summary.pdf`.
- [ ] Complete `ai_usage_log.md` with material prompts, human checks and validation.
- [ ] Test repository from a clean environment.
- [ ] Prepare final presentation, screenshot and project video walkthrough.
- [ ] Publish the requested X post; record the post URL.
- [ ] Submit the post URL and project/code link through the official organizer channel by **October 30, 2026**.

A placeholder file never satisfies a required output. Do not mark a deliverable complete until verified.
